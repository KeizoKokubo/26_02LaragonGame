# Cyber Defense - タワーディフェンス & ランキングシステム

HTML, CSS, JavaScript (Vanilla JS) で作成されたタワーディフェンスゲームです。
到達したWave数と、いかに少ないタワー数で生き残ったか（タワー効率倍率）を評価し、PHP/MySQL (Laragon) と連携してオンラインランキングを記録・表示します。

---

## 🚀 Laragonでのセットアップ & 起動手順

### 1. プロジェクトフォルダの配置
Laragonのドキュメントルート（通常 `C:\laragon\www`）内にこのフォルダ（`P2P`）をコピーするか、現在のフォルダをLaragonのルートまたはシンボリックリンク等でアクセスできるようにします。
> 例: `C:\laragon\www\P2P`

### 2. MySQLデータベースの作成 & インポート
1. Laragonを起動し、**「すべて起動 (Start All)」** をクリックします。
2. Laragonの **「データベース (Database)」**（HeidiSQL または phpMyAdmin）を開きます。
3. プロジェクトルートにある `schema.sql` を実行（インポート）します。
   - `tower_defense_db` データベースと `rankings` テーブルが自動作成されます。

### 3. ゲームのプレイ
ブラウザで以下のURLにアクセスします。
```
http://localhost/P2P/
```
または Laragonの仮想ホスト設定を行っている場合:
```
http://p2p.test/
```

## 🎮 ゲームルール・スコア仕様

1. **基本ルール**:
   - 侵入経路から現れる敵を迎撃します。
   - ライフが0になるとゲームオーバーです。
2. **タワーの種類**:
   - **ガトリング (🪙100)**: 高速連射で単体の敵を迎撃。
   - **キャノン (🪙160)**: 範囲（スプラッシュ）ダメージ。集団の敵に有効。
   - **スナイパー (🪙220)**: 超長射程・高威力。ボスや強敵に有効。
   - 設置済みタワーをクリックすると **強化 (Upgrade)** や **売却 (Sell)** が可能です。
3. **スコアシステム（タワー節約ボーナス）**:
   - スコア = `(基礎撃破ポイント + Waveボーナス) × 効率倍率`
   - **効率倍率**: Wave進行に対して「タワー設置数が少ない」ほど高倍率（最大2.5倍）ボーナスが付与されます。
   - ゲーム終了後、プレイヤー名を入力してスコアを登録すると、DBランキングにリアルタイム反映されます。
